🔹 1. What is SQL?

SQL (Structured Query Language) is a language used to talk to databases.

👉 You use SQL to:

  • Store data

  • Retrieve data

  • Update data

  • Delete data

💡 Example:

SQL
SELECT * FROM students;

This means: “Give me all student data”

👉 SQL is not a programming language like Python — it is a query language.

🔹 2. What is DBMS?

DBMS (Database Management System) is software that helps you store and manage data.

👉 Examples:

  • MySQL

  • Oracle

  • MongoDB

💡 Think like:
👉 DBMS = “Storage system”

🔹 3. What is RDBMS?

RDBMS (Relational DBMS) is a type of DBMS where data is stored in tables (rows & columns) and relationships are maintained.

👉 Examples:

  • MySQL

  • PostgreSQL

  • Oracle

💡 Key idea:
👉 Data is connected using keys (Primary Key & Foreign Key)

🔥 Difference (Very Important)

FeatureDBMSRDBMS
StructureFilesTables
RelationshipsNoYes
NormalizationNoYes
Data RedundancyHighLow

🔹 9. SQL Command Categories

1. DDL (Data Definition Language)

👉 Structure of database

SQL
CREATE TABLE students(id INT, name VARCHAR(50));
ALTER TABLE students ADD age INT;
DROP TABLE students;

2. DML (Data Manipulation Language)

👉 Work with data

SQL
INSERT INTO students VALUES(1,'Ram');
UPDATE students SET name='Shyam';
DELETE FROM students WHERE id=1;

3. DQL (Data Query Language)

👉 Fetch data

SQL
SELECT * FROM students;

4. TCL (Transaction Control Language)

SQL
COMMIT;
ROLLBACK;
SAVEPOINT;

5. DCL (Data Control Language)

SQL
GRANT;
REVOKE;
