# Community Event Manager (Flask demo)

Simple demo: no database, no JavaScript. Data lives in a Python list and resets on restart.
The search/filter panel on the home page is display only.

## Run
    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000

## Files
- app.py             routes + Python validation
- templates/         base, index, details, create, edit, register
- static/style.css   styles
- static/uploads/    uploaded event images
