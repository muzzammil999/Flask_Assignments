# Community Event Manager (Flask demo)

Simple demo: no database, no JavaScript. Data lives in a Python list and resets on restart.

## Run
    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000

## Files
- app.py            routes + Python validation
- templates/        base, home, details, event_form, register
- static/css.css    styles
